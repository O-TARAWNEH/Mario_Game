## Open in Unity

1. Install / use Unity **6000.5.6f1** (or your Unity 6 editor).
2. Unity Hub → **Open** → select this folder (`FORTH_GAME`).
3. Open scene `Assets/Scenes/Bootstrap.unity`.
4. Press Play and check the Console for `[BounderTrail][Bootstrap]` messages.

If the Bootstrap scene is missing, use menu: **Bounder Trail → Phase 1 → Create Bootstrap Scene**.
